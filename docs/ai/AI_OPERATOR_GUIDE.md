# 工具包操作入口

先阅读根目录 README.md。工具包只维护工具和示例；项目应位于工具包以外。

初始化：asapflow plugin init-project --root <外部项目目录> --source <工具包>/content
文档检查：asapflow plugin init-project --root <外部项目目录> --check
文档更新：asapflow plugin init-project --root <外部项目目录> --update

进入项目后读取 docs/dev-kit/README.md 和 docs/dev-kit/ai/AI_OPERATOR_GUIDE.md。
项目 Git 由开发者自行管理。不要覆盖已有业务源码。
